# Claude Starter

A blank, organized folder for working with Claude Code. Set up by RizeTech.

## Set it up (about 5 minutes)

1. Click the green **Code** button above, then **Download ZIP**.
2. Find the zip in your Downloads. Right click it and choose **Extract All** (Windows) or double click it (Mac).
3. Rename the folder to whatever you want (for example "My Sandbox") and move it into Documents.
4. Open **VS Code**. Click **File**, then **Open Folder**, and pick the folder. If it asks whether you trust the folder, click **Yes**.
5. Open Claude Code and type `/setup`. Claude asks you 5 questions and fills in the rest.

That's it. From now on, open this folder in VS Code whenever you want to work in it.

## What's inside

- `CLAUDE.md`: the brain. Claude reads it first every session.
- `context/`: background on you and your goals
- `projects/`: one folder per idea
- `brainstorms/`: rough thinking and interview notes
- `references/`: docs and notes worth keeping
- `decisions/log.md`: what was decided and why
- `connections.md`: tools and accounts this folder can reach
- `archives/`: old stuff. Never delete, move here.

## Skills

Type these in Claude Code:

- `/setup`: answer 5 questions and Claude fills in the brain. Run this first.
- `/grill-me`: Claude interviews you one question at a time to pull an idea out of your head
- `/roast`: five critics tear apart an idea before you spend time on it
- `/storm`: research a topic from several expert angles
- `/fable-mode`: careful mode for hard, multi step work
- `/session-handoff`: end of session summary so the next one picks up where you left off
- `/skill-builder`: make a new skill
- `/excalidraw-diagram`: draw a diagram
